# Student Management REST API

## Deskripsi

Student Management REST API adalah aplikasi pengelolaan data siswa yang dibuat menggunakan Express.js, MySQL, HTML, CSS, dan JavaScript.

Aplikasi ini digunakan untuk menampilkan, menambahkan, mengubah, dan menghapus data siswa melalui REST API.

## Fitur

- Menampilkan seluruh data siswa
- Menampilkan data siswa berdasarkan ID
- Menambahkan data siswa
- Mengubah data siswa
- Menghapus data siswa
- Form tambah siswa
- Form edit siswa
- Konfirmasi sebelum menghapus data
- Loading indicator
- Pesan berhasil
- Pesan error
- Frontend menggunakan JavaScript Fetch API

## Teknologi
